# حربatuan - لعبة حرب بسيطة

 لعبة حرب بسيطة تعتمد على HTML5 Canvas و JavaScript، تعمل مباشرة في المتصفح دون الحاجة إلى تثبيت أي إضافات.

## طريقة اللعب

- **السهم الأيمن / D / زر يمين**: التحرك يميناً
- **السهم الأيسر / A / زر يسار**: التحرك يساراً
- **مسافة (Space) / زر إطلاق**: إطلاق النار

## الهدف

حطم السفن المعادية القادمة من الأعلى قبل أن تصل إليك أو تصيبك. كل سفينة تُدمر تمنحك 100 نقطة. مع كل 500 نقطة، يرتفع المستوى وتزداد صعوبة اللعبة.

## التقنية المستخدمة

- HTML5 Canvas
- JavaScript (ES6)
- CSS3 (متجاوب مع الشاشات اللمسية)

## التشغيل

يمكنك فتح ملف `index.html` مباشرة في أي متصفح ويب لبدء اللعب.

## النشر على GitHub Pages

اذهب إلى Settings > Pages في المستودع، ثم اختر الفرع (master) كمصدر للنشر.
